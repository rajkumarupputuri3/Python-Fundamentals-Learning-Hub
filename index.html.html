Topic 02

Variables

Variables are named containers that store data values. In Python, you don't need to declare the type — it's inferred automatically.

Naming Rules Important
  • Must start with a letter or underscore
  • Can contain letters, digits, underscores
  • Case-sensitive: age ≠ Age
  • Cannot use reserved keywords like if, for
  • Use snake_case by convention
Assignment
python
# Assigning values to variables
name = "Alice"
age = 20
gpa = 3.85
is_student = True

# Multiple assignment
x, y, z = 1, 2, 3
Valid vs Invalid
python
# ✅ Valid names
user_name = "Bob"
_private = 42
score2 = 100

# ❌ Invalid names
# 2score = 100     (starts with digit)
# my-name = "x"   (hyphen not allowed)
# for = 5         (reserved keyword)

Topic 04

Input & Output

Python uses print() to display output and input() to receive user input.

📤
print() — Output

Displays text, variables, and expressions to the console.

python
name = "Alice"
age = 20

# Basic print
print("Hello, World!")

# f-string formatting
print(f"Name: {name}, Age: {age}")

# sep and end options
print("a", "b", "c", sep="-")
Hello, World!
Name: Alice, Age: 20
a-b-c
📥
input() — Input

Pauses execution and waits for the user to type something. Always returns a str.

python
# Basic input
name = input("Enter your name: ")
print(f"Hello, {name}!")

# Converting input to number
age = int(input("Enter your age: "))
print(f"Next year: {age + 1}")
Enter your name: Alice
Hello, Alice!
Topic 05

Type Casting

Type casting converts a value from one data type to another using built-in functions.

int()
Converts a value to an integer. Truncates decimals — does not round.
"42" → 42
python
int("42")    # → 42
int(3.99)   # → 3
int(True)   # → 1
float()
Converts a value to a floating-point (decimal) number.
"3.14" → 3.14
python
float("3.14") # → 3.14
float(5)     # → 5.0
float(False) # → 0.0
str()
Converts any value to its string representation.
100 → "100"
python
str(100)    # → "100"
str(3.14)   # → "3.14"
str(True)   # → "True"
Topic 06

Comments

Comments are ignored by Python's interpreter. They're notes for humans — you and your future self.

Single-Line Comments

Use the # symbol. Everything after it on that line is a comment.

python
# This is a single-line comment
x = 5  # Inline comment

# Comments help explain your logic
total = x * 2  # Multiply x by 2

Multi-Line Comments

Use triple quotes """...""" for multi-line notes (technically a string literal, but used as a comment).

python
"""
This is a multi-line comment.
It can span multiple lines.
Great for function documentation.
"""

def add(a, b):
    """Returns the sum of a and b."""
    return a + b
Practice Project

Simple Calculator

Put everything together to build your first complete Python program. This project uses variables, data types, input/output, type casting, and comments.

Project Breakdown

This calculator takes two numbers and an operator from the user and performs the calculation. It's a perfect first project because it exercises all the fundamentals in one program.

  1. Display a welcome message using print()
  2. Get first number from user with input()
  3. Get second number from user
  4. Get the operator (+, -, *, /)
  5. Cast string inputs to float
  6. Use if-elif-else to pick operation
  7. Print the result
python
# Simple Calculator — Python Project

print("=== Simple Calculator ===")

# Get inputs from user
num1 = float(input("Enter first number: "))
num2 = float(input("Enter second number: "))
op = input("Enter operator (+, -, *, /): ")

# Perform the calculation
if op == "+":
    result = num1 + num2
elif op == "-":
    result = num1 - num2
elif op == "*":
    result = num1 * num2
elif op == "/":
    if num2 != 0:
        result = num1 / num2
    else:
        print("Error: Division by zero!")
        result = None
else:
    print("Invalid operator!")
    result = None

# Show result
if result is not None:
    print(f"Result: {num1} {op} {num2} = {result}")

Pro Tips

Tips & Tricks

⚡
Use f-strings
f-strings (Python 3.6+) are the fastest and most readable way to format strings. Prefer f"Hello, {name}" over concatenation.
🔍
Use type() to Debug
When something doesn't work, wrap the value in print(type(x)) to see exactly what type Python thinks it is.
📝
Comment as You Go
Write comments before you write code. Explaining what you intend to do often reveals the logic before you even type it.
🐍
Python is Indentation-Sensitive
Unlike most languages, Python uses indentation (4 spaces) to define code blocks. Inconsistent indentation causes IndentationError.
🔢
input() Always Returns str
Even if the user types 42, input() returns the string "42". Always cast it if you need a number.
📚
Use the Python Docs
The official Python documentation at docs.python.org is thorough, accurate, and free. Make it your first stop.
FAQ

Frequently Asked Questions

Do I need to know math to learn Python? ▾
No, you don't need advanced math. Basic arithmetic (addition, subtraction, multiplication, division) is sufficient for most beginner and intermediate Python programs. Math becomes more important if you go into data science or machine learning later on.
What's the difference between int and float? ▾
int stores whole numbers like 5 or -100. float stores decimal numbers like 3.14 or -0.5. Division of two integers in Python 3 always returns a float.
Can I use Python without VS Code? ▾
Absolutely. You can use any text editor (Notepad, Sublime Text, Vim) or IDEs like PyCharm. VS Code is recommended for beginners because it's free, lightweight, and has excellent Python support via extensions.
Why does Python use indentation instead of brackets? ▾
Python's creator Guido van Rossum designed it this way to enforce readability. Indentation-based blocks eliminate the visual noise of curly braces {} and ensure code is always formatted consistently.
What happens if I try to add a string and a number? ▾
Python will throw a TypeError. You must explicitly cast one type to the other first: either str(42) to turn the number into a string, or int("42") to turn the string into a number.
